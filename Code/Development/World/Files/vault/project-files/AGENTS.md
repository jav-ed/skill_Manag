# Coding related

1. If you start fresh, read the doc start skills (`doc-start`).
2. When you start coding, read the `coding` skill first.
3. No soft fallbacks. We prefer hard errors with very descriptive error messages.
4. Short and to-the-point comments are helpful.
5. Don't use AI agents unless the user asks for them.
6. Run the tests before you say a change is done.
