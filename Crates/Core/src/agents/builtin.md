# Coding related

1. If you start fresh, read the doc start skills (`doc-start`). They will inshallah tell you how to read the doc start md file.
2. If you see that you need to make big changes, use the coding skills (`coding`) and the file-tree optimization skills (`file-tree-optimization`), and suggest a file tree to maintain/optimize code readability and scalability.
3. No soft fallbacks. We prefer hard errors with very descriptive error messages. They inshallah help to debug quickly.
4. Short and to-the-point comments are helpful. They help others understand decisions (user defined, performance, etc.).
5. Don't use AI agents unless the user asks for them.
